# تكوين | Takween - Linktree

صفحة هبوط وروابط تواصل تفاعلية مستوحاة من هوية **تكوين (Takween)** للطباعة ثلاثية الأبعاد والتصنيع الرقمي، بتصميم متجاوب وسلس يعكس روح العلامة التجارية.

---

## 🌟 مميزات المشروع

- **هوية بصرية متكاملة:** مطابقة لكارت وألوان الهوية الرسمية (الأزرق الملكي `#1c4488` والذهبي `#d2b031`).
- **خلفية فيكتور نقية (100% Vector):** ووترمارك مخصص بشعار تكوين يظهر بتدرج انسيابي في الزاوية العلوية اليمنى والسفلية اليسرى بدون أي بكسلة.
- **خط ثمانية سانس (Thmanyah Sans):** مدمج ومستضاف محلياً بالكامل بصيغة `.woff2` (بدون أي اعتماديات خارجية أو CDN).
- **بيانات ديناميكية:** يتم جلب كافة الروابط وقنوات التواصل والكتالوج من ملف [`data.json`](data.json) مع دعم العمل دون اتصال.
- **تفاعل ومشاركة:** نافذة مشاركة سريعة، نسخ تلقائي لرقم الواتساب والروابط مع إشعارات Toast تفاعلية.
- **تصميم متجاوب بالكامل:** متناسق 100% مع شاشات الهواتف الذكية، الأجهزة اللوحية، وشاشات سطح المكتب.

## 📁 هيكل المشروع

```
├── index.html          # الصفحة الرئيسية والهيكل البصري
├── style.css           # التنسيقات وتأثيرات الهوية البصرية
├── script.js           # جلب البيانات والتفاعلات ونسخ الروابط
├── data.json           # ملف البيانات (الروابط، الكتالوج، أرقام التواصل)
├── logo.svg            # شعار تكوين الرسمي
├── icon.svg            # أيقونة الشعار الهندسية
├── background.svg      # خلفية الووترمارك الفيكتور الكاملة
├── colors.ai           # ملف ألوان الهوية
└── fonts/              # خط Thmanyah Sans المستضاف محلياً
    ├── thmanyah-sans.css
    └── thmanyah-sans/  # ملفات .woff2 بالأوزان المختلفة
```

## 🚀 التشغيل المباشر

يمكنك فتح `index.html` مباشرة في المتصفح، أو تشغيل سيرفر محلي بسيط:

```bash
# باستخدام Python
python -m http.server 5173
```

ثم الدخول على الرابط: `http://localhost:5173`

---

## 🌐 النشر على GitHub Pages

المشروع جاهز للنشر مباشرة عبر **GitHub Pages**:
1. اذهب إلى إعدادات المستودع **Settings** > **Pages**.
2. اختر الفرع `main` والمجلد `/ (root)`.
3. اضغط **Save** وسيكون موقعك متاحاً مجاناً أونلاين.
